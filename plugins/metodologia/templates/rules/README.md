# Rules de ejemplo

Se copian a `.claude/rules/` del proyecto y se cargan **solo** al tocar archivos que matchean `paths:`.
Ajustá los `paths:` a los directorios reales y reemplazá los ejemplos por las convenciones del proyecto.

- `rails-migrations.md`, `rails-specs.md` → apps Rails
- `frontend-tests.md`, `frontend-ui.md` → frontends JS/TS
- `review-rails.md`, `review-react.md` → checklist **propio del proyecto** que leen los reviewers del plugin
